## 使用约定

- PRD 编号为 `PRD-001`，具体需求使用稳定 ID，例如 `REQ-BLE-001`。变更按顺序使用 `CR-001`，编号不重复使用。
- 审批状态与交付状态分别维护。审批通过不代表功能已实现，实现完成不代表验收通过。
- 提出新需求时先写变更提案，保持现行批准版本有效；批准后再同步 PRD、索引和相关设计。
- 变更范围明确且已有用户批准时直接继续，不为同一决定重复申请批准。
