# 蓝牙控制与动作中心验收用例

版本：0.2｜状态：approved｜制定 2026-10-08，用户批准 2026-10-09｜关联 CR-005 v0.2。以下标准已随 CR-005 批准，不是执行结果。

| ID / 需求 | 层级与前置 | 操作与可观察预期 |
|---|---|---|
| TC-CTL-03 / REQ-CTL-001/002 | 控制器 / widget、模拟 ready | 八方向分别输入，检查 1～8 空载荷；中心区无方向；拖动方向更换只保留最新意图，松手 / 取消不再发旧方向 |
| TC-CTL-04 / REQ-CTL-001 | 触摸 / 生命周期 / 阻塞写入 | 多指、拖出、切页、后台、断线；旧定时器、排队命令失效，链路有效时尝试停止，重连不恢复旧运动 |
| TC-CTL-05 / REQ-CTL-003 | 文件仓库 / 选择面板 | 默认三项、替换、确认 / 取消、恢复默认、结束并重开；绑定路径 / 名称一致；损坏 / 未知版本不覆盖；存储失败不伪报成功 |
| TC-CTL-06 / REQ-CTL-003 | 协议 / 平台编码、可信中文向量 | 中文完整路径 GB18030 编码与预期字节一致；中文目录回传正确解码；无损往返不能单独作为编码依据 |
| TC-CTL-07 / REQ-CTL-003 | 模拟状态机 / 通知 | 0x17 写入不等于完成；播放与摇杆 / 编程互斥；停止请求不误报物理停止；无回传 / 迟到 / 空载荷 / 断线保持准确状态，新会话不自动重播 |
| TC-CTL-08 / REQ-CTL-004/005 | 模拟时钟 / 状态 | 快速修改音量，500ms 后只有最后值；回传更新不产生写入；切页 / 断线取消旧设置；短状态电量未知，不显示假零百分比 |
| TC-BLE-05 / REQ-BLE-001 | 模拟扫描与错误 GATT | K1 / k1 前缀候选可见；GSEG- 不成为支持设备；错服务或无握手不 ready |
| TC-CTL-09 / REQ-CTL-001～005、REQ-ACC-001 | Android、iOS、K1AI；已记录固件 / 映射 / 停止方式 | 与原 APK 对照八方向、快捷动作、音量、停止和异常状态，保存日志与机器人录像；分别记录 K1 缺口，不用构建 / 模拟通过判实机通过 |
| TC-ACT-01 / REQ-ACT-001 | 离线服务与 codec；T06b 已确认的目录请求向量、三目录回传样本 | 按原表查询三目录，每个目录可回传多个 0x16，RX 0xFA 才结束；多个通知切片可正确解析；全过程不得 TX 0xFA。不以一次 0x16 或 GATT 完成提前标完整 |
| TC-ACT-02 / REQ-ACT-001 | 目录模型 / widget；明确标为模拟的中文、同名、长名单、空目录样本 | 三目录全部有效条目可访问，跨目录同名保留，分类计数和全部计数正确；中文与名称原样显示，长名单末项可达；刷新增删后正确更新，默认 ProAction 快捷项不冒充目录条目 |
| TC-ACT-03 / REQ-ACT-001 | 模拟通知 / 时钟；超时、坏编码、资源限制、断线、取消、迟到样本 | 真实结束后的空目录与未读完整区分；部分失败不显示全量完成；未确认旧事务结束时不开始新查询，不把迟到结束挂到另一目录；新设备重新读取，不显示旧设备的假完整结果 |
| TC-ACT-04 / REQ-ACT-002、REQ-CTL-003 | 模拟播放、已核对 GB18030 向量及完整路径 | 各类别任意条目播放均使用该目录和原名，无猜测扩展名处理；目录 / 快捷 / 摇杆 / 编程互斥。进度 100 正常完成，101 / 空载荷不误报完成；停止、无回传、断线、迟到回传不产生假成功或重播 |
| TC-ACT-05 / REQ-ACT-002、REQ-CTL-003、REQ-UX-001 | 文件仓库 / widget / 手机触摸 | 普通模式选择播放，绑定模式选择不播放；任意三目录条目可绑定并保存 / 重开；刷新或换设备后不可用绑定保持原信息，不改绑同名动作；横竖屏列表、计数、刷新、返回、停止可操作 |
| TC-ACT-06 / REQ-ACT-001、REQ-ACC-001 | Android、iOS、同一 K1AI 与固件、原 APK；目录内容在对照期间不变 | 原版和新应用分别保存完整目录 / 名称 / 路径及总数，比较集合和各分类，缺失 / 多出项逐项记录；三个目录均结束且集合一致才通过。K1 单独记录，不自动沿用 K1AI 结果 |
| TC-ACT-07 / REQ-ACT-002、REQ-ACC-001 | TC-ACT-06 名单、确认型号 / 固件 / 运动空间及停止条件 | Android、iOS 分别逐项与原版对照实际动作、路径、进度和结束表现；停止 / 断线异常使用已确定适合的代表动作另测。每条路径记录 passed / failed / not_run，未运行项不能算全量播放通过 |

证据记录沿用测试规范：代码 / 应用版本、系统、型号、固件、操作者、输入、步骤、实际结果、日志 / 录像及 passed / failed / blocked / not_run。测试不能执行未确认的任意机器人命令。

清理：离线测试释放流、计时器与临时仓库；手机测试恢复本轮前的快捷配置，退出控制 / 动作页并断开连接，记录机器人实际状态，不删除机器人动作。实机原版 / 新版依次连接，避免同时占用 BLE；对照期间新增 / 删除文件则重新采集目录快照。使用静态向量或测试替身不需要机器人运动，不能冒充 TC-ACT-06/07。
