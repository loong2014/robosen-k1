## 实现约定

- 页面不拼协议字节；transport、codec、session、control、工程模型与持久化独立。
- 自有工程 schemaVersion=1，含稳定 ID、机器人型号、根节点、顺序子节点、参数和位置。未知字段/版本拒绝加载和覆盖；损坏 JSON 可以恢复上一份有效备份，损坏原件另存。
- 1000 节点、32 层、100 次循环、展开 10000 动作为本地资源限制，不宣称为固件限制。
- 当前编辑参数为临时原始数值表示；不是已校准角度/毫秒/转速。动作格式核对后需要同步合法域和 UI，不能静默映射。
- 控制暂用 100ms 周期、停止五次间隔 200ms；停止重复来自 APK，运动节奏仍待实机。断线只能停止应用发送，无法证明物理停止。
- 业务 ACK 与 GATT 写入分离。无机器人协议序号，禁止自动重发不确定的文件写入。
