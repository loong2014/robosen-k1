## 背景与范围

用户询问现有原生 BLE 和积木分析是否足以开始应用生产。本轮已核对资料并形成可审阅启动方案。该询问未自动批准此前尚未提出的具体功能子集、最低系统和技术选型；CR-001/002 已批准内容继续有效。

详细任务：[实施计划](../../docs/development/implementation-plan.md)。技术：[架构](../../docs/technical/architecture.md)、[ADR-001](../../docs/technical/decisions/ADR-001-首版技术基线.md)、[依赖清单](../../docs/technical/dependencies.md)。验收：[用例草案](../../docs/testing/acceptance-cases.md)。以上同为本次待审方案，避免用户逐份重复批准。

## 具体化提案

| 需求 ID | 原状态 | 拟确认内容 |
|---|---|---|
| REQ-BLE-001 | 细节待定 | 单设备扫描选择、连接/断开/手动重连；权限、蓝牙状态、业务握手和错误恢复 |
| REQ-CTL-001 | 动作集合待定 | 首批四方向与停止；释放/取消/离开页面/后台停止方向发送；断线不恢复旧运动；实机效果参照 APK |
| REQ-VIS-001 | 积木和界面待定 | 起始、动作（关节目标及速度/延时）、有限次循环；连接排序、参数编辑、删除、保存重开、上传执行；可离线编辑 |
| REQ-PLT-002（新增待批） | 最低版本待定 | 应用支持下限 Android API 24、iOS 15；具体构建及真机兼容由测试证明 |
| REQ-UX-001（新增待批） | 界面未定 | 中文 Flutter 原生四页流程：连接、控制、工程列表、积木编辑；暂不要求原 APK 像素复刻和 3D 预览 |

暂停/恢复、额外预置动作、判断、舞蹈、音频等暂不列入此首批范围。若用户需要，应在批准前调整本方案。速度、延时、关节参数不能在缺少证据时虚构单位和边界。
